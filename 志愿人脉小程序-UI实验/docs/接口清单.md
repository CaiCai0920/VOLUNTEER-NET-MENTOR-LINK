## 三、页面能调的接口（复制函数名字去用就行）

### 社区页（页面已就位，2026-10-07 从组长仓库移植）

> ⚠️ **社区的数据层是 `utils/community.js`，不是 `store.js`。**
> `store.js` 里那份同名函数已标注【已废弃】，页面一律不要再调它。
>
> `require('../utils/community')` 之后：

| 干什么 | 调这个 | 说明 |
|---|---|---|
| 拿帖子列表 | `community.listPosts(条数)` | 按时间从新到旧，默认 50。**注意：不按话题筛** |
| 拿单条帖子 | `community.getPost(帖子id)` | 详情页用 |
| 发帖 | `community.createPost(我, { content, topic, media })` | media 是 `[{type,path}]` |
| 认领答疑帖 | `community.claimPost(帖子, 我)` | 认领后会**自动建一条答疑会话**，学长工作台可见 |
| 上传图片/视频 | `community.uploadMedias(我的id, 文件列表)` | 传给云存储，返回 `[{type,path}]` |
| 换图片可访问链接 | `community.signedUrlsOf(路径数组)` | 云存储是私有的，**必须换签名链接才能显示** |
| 话题清单 | `community.TOPICS` | 9 个：答疑 / 生活 / 校园 / 美食 / 穿搭 / 运动 / 游戏 / 学习 / 闲置 |

帖子每条长这样：

```
id          帖子编号
userId      发帖人编号
userName    发帖人昵称
userRole    mentor（学长）/ asker（新生）
content     正文
topic       话题（见上面 9 个）
media       配图/视频 [{ type: 'image'|'video', path: '云存储路径' }]
createdAt   发布时间
claimedBy   被谁认领了（空 = 还没人接）
claimedAt   认领时间
```

> ⚠️ 两个坑：
> 1. **`media` 里的 `path` 是云存储私有路径，不能直接放进 `<image src>`**，必须先用 `signedUrlsOf()` 换成临时链接（1 小时有效）。
> 2. 帖子话题（上面 9 个）和学长擅长话题（选课/保研/竞赛…）**是两套词，别混用**。

## 四、在线状态：别信 `online` 这个字段

用户表里有一个 `online` 字段，**页面不要用它判断在线**。

- 小程序没有可靠的「下线」通知：用户强杀微信、断网、手机息屏，都不会告诉你。**那个 `true` 永远没人改回 `false`**，所以之前才会出现"说过话的人全都挂着不掉"。
- **正确做法**：只看 `lastActive`（最后一次心跳时间），**40 秒内**算在线。
- 页面要每 15 秒调一次 `touchActive()` 上报心跳，否则你自己也会显示成离线。

> 你如果在大厅看到 6 个名字永远在线 —— 那是程序内置的示例假人（`SEED_MENTORS`），不是真人有 bug。

## 五、三条规矩（比技术重要）

1. **各改各的**：页面文件给做界面的同学，`utils/store.js` 给后端。**要动对方的文件，先在群里说一声。**
2. **改之前先拿最新的**：现在的真相多于一份，动手前先确认自己拿到的是主线最新的那份，别抱着三天的旧版本改一整天。
3. **数据包里有机密**：那份导出的数据包里有两个同学的**真实手机号、姓名学号，还有 4 张学生证照片**。**绝对不要传进 GitHub 仓库**，演示汇报前记得打码。
