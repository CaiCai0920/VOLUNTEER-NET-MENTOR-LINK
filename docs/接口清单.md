## 三、页面能调的接口（复制函数名字去用就行）

### 社区页（还没做，需要先搭页面）

| 干什么 | 调这个 | 说明 |
|---|---|---|
| 拿帖子列表 | `listPosts(话题)` | 不传 = 全部；按时间从新到旧 |
| 拿分类标签 | `listPostTopics()` | 返回「话题 + 各有几条」，第一个是「全部」 |
| 发一条帖子 | `createPost({ content, topic, media })` | media 是图片地址数组，不传就是没图 |
| 认领一条帖子 | `claimPost(帖子id, 认领人)` | 已经被别人接走的会失败，不会两个人同时抢到 |
| 看我发的帖子 | `postsOf(用户id)` | |
| 删自己的帖子 | `removePost(帖子id, 用户id)` | 只能删自己发的 |

帖子每条长这样：

```
id          帖子编号
userId      发帖人编号
userName    发帖人昵称
userRole    mentor（学长）/ asker（新生）
content     正文
media       配图（数组，可能为空）
topic       话题（校园 / 美食 / 生活 / 答疑 …）
createdAt   发布时间
claimedBy   被谁认领了（空 = 还没人接）
claimedAt   认领时间
```

> ⚠️ 注意：帖子的话题（校园 / 美食 / 生活 / 答疑）和学长擅长的话题（选课 / 保研 / 竞赛 …）**是两套不一样的词**，别混着用。

## 四、在线状态：别信 `online` 这个字段

用户表里有一个 `online` 字段，**页面不要用它判断在线**。

- 小程序没有可靠的「下线」通知：用户强杀微信、断网、手机息屏，都不会告诉你。**那个 `true` 永远没人改回 `false`**，所以之前才会出现"说过话的人全都挂着不掉"。
- **正确做法**：只看 `lastActive`（最后一次心跳时间），**40 秒内**算在线。
- 页面要每 15 秒调一次 `touchActive()` 上报心跳，否则你自己也会显示成离线。

> 你如果在大厅看到 6 个名字永远在线 —— 那是程序内置的示例假人（`SEED_MENTORS`），不是真人有 bug。

1. **各改各的**：页面文件给做界面的同学，`utils/store.js` 给后端。**要动对方的文件，先在群里说一声。**
2. **改之前先拿最新的**：现在的真相多于一份，动手前先确认自己拿到的是主线最新的那份，别抱着三天的旧版本改一整天。
3. **数据包里有机密**：那份导出的数据包里有两个同学的**真实手机号、姓名学号，还有 4 张学生证照片**。**绝对不要传进 GitHub 仓库**，演示汇报前记得打码。
